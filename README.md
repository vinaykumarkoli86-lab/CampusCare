# CAMPUSCARE – Smart Campus Complaint Management System

## About the Project

CAMPUSCARE is a Smart Campus Complaint Management System developed as a hackathon project using Google AI Studio.

The platform aims to simplify campus complaint management by providing a digital solution for students to report campus issues and help the administration manage and track complaints efficiently.

## Features

- Digital campus complaint management
- Easy complaint reporting
- Complaint tracking
- Improved communication between students and administration
- Smart campus management concept

## Technology Used

- Google AI Studio
- TypeScript
- HTML
- AI-powered development

## Project Goal

To make campus complaint management easier, more transparent, and more efficient through a digital platform.
